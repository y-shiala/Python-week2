# Discount Calculator

This Python script allows users to input the original price of an item and a discount percentage. If the discount is 20% or higher, it applies the discount and displays the final price. Otherwise, it returns the original price.

## Features

- Accepts user input for original price and discount percentage
- Applies discount only if it is 20% or more
- Prevents invalid input using error handling
- Outputs the final price with proper formatting

## How to Use

1. Make sure you have Python installed (version 3.6 or later).
2. Run the script:
   ```bash
   python discount.py
